## 調査で確認した内容

- 対象と方法: README の読者とプロジェクトの種類に応じ、概要、導入、使用例などの必要な節を選ぶ。
- 参考になる点: 初めて訪れた読者が何のリポジトリか把握し、最初の成功まで進む経路を設計できる。
- 適用上の注意: README 専用として扱い、要件定義書や一般の報告書にテンプレートを流用しない。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| README の読者と最初の作業を意識する | 条件付き | README 執筆の依頼で、読後の行動を確認する。 |
| README 固有の節構成を汎用化する | 見送る | 仕様書や報告書には必要な情報が異なる。 |

## 結論

この対象から現行スキルへ直ちに追加する項目はない。条件付き・保留の項目は、実文書で不足が確認された場合に再検討する。この判断は調査記録と現行スキルの照合であり、対象スキルを導入して出力品質を比較した結果ではない。
