# ux-writing の採否検討

調査対象: [ux-writing](https://github.com/content-designer/ux-writing-skill/blob/main/SKILL.md)  
調査記録: [cognitive-load-writing-skills-research.md](../../cognitive-load-writing-skills-research.md) の「調査時に除外した候補」  
[照合先: write-clear-japanese](../../../../../skills/write-clear-japanese/SKILL.md)

## 調査で確認した内容

UI 文言の観点は有用だが、文長・読解水準・理解率を普遍的な数値基準のように記す箇所があるため、調査の主要候補から外された。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| UI 文言の対象者と次の行動を明確にする | 条件付き | UI 文言を書く案件では参考になるが、画面状態と併せて確認する。 |
| 数値基準を日本語文書の合格値にする | 見送る | 読者・媒体ごとの実証がない。 |

## 結論

現行の `write-clear-japanese` に、この対象から直ちに追加する項目はない。必要に応じて対象用途の実例で再検討する。この判断は既存調査の記述に基づき、対象スキルの効果を実測した結果ではない。
