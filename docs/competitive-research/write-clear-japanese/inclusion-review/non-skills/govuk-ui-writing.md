# GOV.UK のコンテンツ設計 の採否検討

調査対象: [GOV.UK のコンテンツ設計](https://www.gov.uk/service-manual/design/writing-for-user-interfaces/)  
調査記録: [low-cognitive-load-writing-research.md](../../low-cognitive-load-writing-research.md)  
[照合先: write-clear-japanese](../../../../../skills/write-clear-japanese/SKILL.md)

## 調査で確認した内容

UI の利用者に合わせたコンテンツ設計の資料として参照される。具体的な画面文言は利用状況と併せて判断する必要がある。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| 対象者と次の行動を明確にする | 条件付き | UI 文言を書く場合に確認する。 |
| UI 固有の規則を全文章へ適用する | 見送る | 報告や解説には目的が異なる。 |

## 結論

現行スキルへの新規追加は実例で不足を確認してから判断する。検討対象は「対象者と次の行動を明確にする」。この判断は既存の調査記録と現行スキルの照合であり、資料の効果を新たに実測した結果ではない。
