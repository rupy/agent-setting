# 文書テンプレートのユーザーテスト研究 の採否検討

調査対象: [文書テンプレートのユーザーテスト研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC4596875/)  
調査記録: [low-cognitive-load-writing-research.md](../../low-cognitive-load-writing-research.md)  
[照合先: write-clear-japanese](../../../../../skills/write-clear-japanese/SKILL.md)

## 調査で確認した内容

文書テンプレートを利用者の探索課題で試す研究として参照される。元調査は見出しの数ではなく探しやすさを確認する方向に使う。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| 見出しと構成を読者の探索で試す | 条件付き | 規模や影響の大きい文書で検証する。 |
| 見出し数を固定する | 見送る | 探索課題による確認が必要。 |

## 結論

現行スキルへの新規追加は実例で不足を確認してから判断する。検討対象は「見出しと構成を読者の探索で試す」。この判断は既存の調査記録と現行スキルの照合であり、資料の効果を新たに実測した結果ではない。
