# Easy Read の試験 の採否検討

調査対象: [Easy Read の試験](https://pubmed.ncbi.nlm.nih.gov/31652030/)  
調査記録: [low-cognitive-load-writing-research.md](../../low-cognitive-load-writing-research.md)  
[照合先: write-clear-japanese](../../../../../skills/write-clear-japanese/SKILL.md)

## 調査で確認した内容

知的障害のある成人を対象とした試験で、言語の単純化だけによる理解度の有意な改善は確認されなかった。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| 読みやすさを実際の理解で確かめる | 条件付き | 対象読者が明確な高影響文書で検討する。 |
| 単語と文長の調整だけで理解を保証する | 見送る | 試験結果が支持しない。 |

## 結論

現行スキルへの新規追加は実例で不足を確認してから判断する。検討対象は「読みやすさを実際の理解で確かめる」。この判断は既存の調査記録と現行スキルの照合であり、資料の効果を新たに実測した結果ではない。
