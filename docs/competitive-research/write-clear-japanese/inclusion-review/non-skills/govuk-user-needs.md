# GOV.UK の利用者ニーズ の採否検討

調査対象: [GOV.UK の利用者ニーズ](https://guidance.publishing.service.gov.uk/writing-to-gov-uk-standards/plan-manage-content/identify-user-needs/)  
調査記録: [low-cognitive-load-writing-research.md](../../low-cognitive-load-writing-research.md)  
[照合先: write-clear-japanese](../../../../../skills/write-clear-japanese/SKILL.md)

## 調査で確認した内容

利用者の必要を行動や課題として記述し、調査や分析で確かめる考え方を示す。

## スキルに含める項目リスト

| 項目 | 判断 | 理由と入れる内容 |
| --- | --- | --- |
| 読者が何を判断・実行するか決める | 既存で対応 | 書く前の確認にある。 |
| 必要情報の欠落を読者で検証する | 条件付き | 影響の大きい文書で実施する。 |

## 結論

現行スキルへの新規追加は実例で不足を確認してから判断する。検討対象は「必要情報の欠落を読者で検証する」。この判断は既存の調査記録と現行スキルの照合であり、資料の効果を新たに実測した結果ではない。
