# 要求を明確にするためのスキル調査

調査日: 2026-09-21

曖昧な構想から、目的、対象範囲、制約、未決事項を整理するためのスキルを調べる。既存の `create-requirements-docs` に渡す情報をどう集めるかが主な対象である。

| 資料 | 内容 |
| --- | --- |
| [grilling の調査](grilling-research.md) | 質問の進め方、関連スキルとの分担、現行スキルとの比較、確認できた限界 |
| [grilling の採否検討](inclusion-review/grilling.md) | 取り入れる候補、そのまま採用しない指示、試す際の確認項目 |

採否検討は変更の提案であり、既存スキルへの反映や導入が済んだことを示すものではない。
