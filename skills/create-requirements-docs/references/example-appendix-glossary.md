# 用語集

## 業務用語

| 用語 | 定義 | 備考 |
|---|---|---|
| 経費申請 | 一つ以上の経費明細をまとめた申請単位 | 申請番号を持つ |
| 経費明細 | 一回の支払いに対応する情報 | 支払日、金額などを持つ |
| 差し戻し | 修正を求めて申請を申請者へ戻すこと | 理由の入力を必須とする |

## システム用語

| 用語 | 定義 | 備考 |
|---|---|---|
| 上長承認待ち | 直属上長の判断を待つ申請状態 | 提出直後の状態 |
| 会計連携済み | 会計CSVの出力対象になった状態 | 会計取込成功とは区別する |

## 略語

| 略語 | 正式名称 | 意味 |
|---|---|---|
| RPO | Recovery Point Objective | 許容できるデータ損失時点 |
| RTO | Recovery Time Objective | 復旧までの目標時間 |

## 使用を避ける曖昧な表現

「迅速に」「適切に」「必要に応じて」「可能な限り」は、条件、判断者、目標値を定義せずに使用しない。
