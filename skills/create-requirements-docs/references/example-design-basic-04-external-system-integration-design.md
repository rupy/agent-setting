```markdown
# 外部システム連携設計

## 1. この文書で決めること
IF-001からIF-004を実現する外部接続、入出力、タイミング、異常時の処理を定義する。アプリケーション内部の呼出しは詳細設計へ記載する。

## 2. 外部連携一覧
| 連携先 | 方向 | 方式 | 主な入出力 | 関連要件 |
|---|---|---|---|---|
| 社内認証 | 双方向 | OpenID Connect | 認証要求、IDトークン | IF-001、CON-002 |
| 組織情報取込 | 人事→経費 | CSV | 従業員、部署、上長 | IF-002 |
| メール通知 | 経費→メール | HTTPS API | 宛先、テンプレートID | IF-003 |
| 会計連携 | 経費→会計 | CSV | 承認済み経費 | IF-004、DEC-001 |

## 3. 入出力と接続方法
認証は認可コードフロー、メール通知はサービス認証を使用する。組織情報は毎日1回、会計CSVは経理担当者の操作時に生成する。CSV項目は各外部仕様との対応表で管理する。

## 4. エラー・再送・監視
認証失敗はログインを中止する。組織取込は行単位で検証して再取込し、通知は処理IDで重複を防いで再試行する。会計CSVの出力失敗は経理担当者へ表示し、連携失敗を監視対象とする。

## 5. 設計上の判断と未確定事項
- 設計判断: DEC-001に基づき、初回の会計連携はCSV方式とする。
- ISSUE-024: 組織情報CSVの文字コード。
- ISSUE-025: 会計取込エラーコードの対応表。
```
