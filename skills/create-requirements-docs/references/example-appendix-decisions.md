```markdown
## 決定事項

### DEC-001 初回リリースの会計連携方式

- ステータス: decided
- 決定日: 2026-08-20
- 決定者: プロジェクト責任者、経理部責任者
- 背景: 会計APIの利用には追加契約が必要である。
- 選択肢: API連携、CSV連携、手入力
- 決定: 初回リリースではCSV連携とする。
- 理由: 追加契約なしで既存の取込機能を利用できるため。
- 影響: 経理担当者によるCSV出力と取込操作が残る。
```
