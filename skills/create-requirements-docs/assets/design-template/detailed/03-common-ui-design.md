# 共通UI詳細設計

## 1. この文書で決めること
SCR-001からSCR-003に共通する入力、状態表示、端末対応、アクセシビリティの実装仕様を定義する。

## 2. 入力と検証の共通仕様
必須項目にはラベル上で必須と表示する。形式検証はフォーカス移動時、業務検証は提出時に行い、エラーになっていない入力値は保持する。

## 3. エラー・確認・完了表示
項目エラーは入力欄の直下、処理全体のエラーは画面上部に表示する。原因と次に取れる行動を併記し、破棄を伴う操作は実行前に確認する。

## 4. 端末・画面サイズ別の振る舞い
画面幅768px未満では一列構成とし、一覧の補助列を非表示にする。主要操作は画面下部へ固定せず、内容の直後に配置する。

## 5. アクセシビリティの実装仕様
すべての入力にプログラムから判別可能なラベルを付ける。エラー概要から対象項目へフォーカスを移動でき、状態は色とテキストの両方で示す。

## 6. 文言・共通部品
業務用語集に従い、「登録」「提出」「承認」を区別する。ボタン、入力、通知、ダイアログは共通UI部品を使用する。

## 7. 設計上の判断と未確定事項
- 設計判断: エラー概要と項目エラーを併用する。
- ISSUE-030: 領収書撮影時の画像補正要否。
