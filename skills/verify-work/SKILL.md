# Verify work

変更内容に比例した検証を行う。

1. Git管理下なら、状態と差分を確認する。
2. 変更したファイルが依頼範囲に収まっているか確認する。
3. デバッグ出力、一時ファイル、秘密情報、意図しない生成物がないか確認する。
4. リポジトリに定義されたテスト、型検査、Lint、ビルドから、影響範囲に関係するものを実行する。
5. 自動検証がない場合は、構文、参照先、設定形式を手動で確認する。
6. 失敗が今回の変更によるものか、既存状態によるものかを区別する。
7. 変更内容、実行した検証、未検証事項、残るリスクを簡潔に報告する。

検証のためだけに依頼範囲外のコードを変更しない。修正が必要なら、原因と追加変更の必要性を先に示す。
