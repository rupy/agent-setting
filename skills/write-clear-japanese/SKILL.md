# 伝わる日本語を書く

読み手が必要な判断や作業を進められる文章にする。依頼された文書の目的、読者、文体、長さ、用語、構成を優先する。既存文書を直す場合は、事実、数値、引用、判断の強さを勝手に変えない。

## 書く前に決めること

- 読者が読み終えたあとに何を理解し、何を判断または実行するかを確認する。依頼文や周辺資料から分かる場合は質問を増やさない。
- 読者が既に知っている用語と、説明が必要な用語を分ける。初出の専門語は短く定義し、以後は同じ呼び方を使う。
- 事実、推測、提案、未決事項を区別する。根拠がない数値や事例を補わない。例を創作するなら架空と明示する。

## 文章の組み立て

- 段落ごとに一つの話題を扱う。冒頭で話題を示し、その段落内で理由、具体例、帰結を必要な範囲だけ述べる。
- 結論や依頼事項を読者が探さずに済む位置へ置く。背景がないと誤解する場合は、必要な背景を先に示す。
- 原因と結果を結ぶときは、途中で何が起こるかを書く。単なる前後関係から因果を断定しない。
- 指示語が複数の対象を指し得るときは、対象名を書き直す。箇条書きや表は、比較軸や手順を見せる場合に使う。
- 見出しは、その下にある内容を予測できる具体的な語句にする。見出しだけで文章の筋を追えるか確認する。

## 言い回し

- 主語と動作を特定できる文にする。「対応する」「検討する」などで終える場合は、対象と作業内容を補う。
- 日本語で自然な動詞を選ぶ。英語の比喩を直訳したような表現や、抽象物が意志を持つような擬人化は、意味が伝わりにくければ具体的な処理や状態に言い換える。
- 文章を飾るだけの強調、前置き、総括を削る。同じ内容の言い換えを重ねない。ただし、条件や例外を理解するために必要な反復は残す。
- 丁寧さは読者と文書の用途に合わせる。文末を機械的に統一して、不自然な日本語にしない。

## 推敲の確認

1. 読者が前に戻らずに、用語、指示先、論理のつながりを追えるか。
2. 主張の範囲が根拠や例の範囲を超えていないか。未確認のことを断定していないか。
3. 一文を短くするために、条件、責任主体、操作の順序を落としていないか。
4. 各段落と見出しに固有の役割があるか。役割のない文や重複した節を削れるか。

推敲の依頼では、原文の意図を保った完成稿をまず示す。意味が変わり得る修正や、根拠が不足して判断できない箇所だけを簡潔に伝える。
