技術構成・採用技術

1. この文書で決めること

経費精算システムの開発・実行・運用に使用する主要な技術と製品を一覧化する。構成や設定の詳細は各設計文書、候補比較と判断理由はADRを正本とする。

2. 採用技術一覧

技術領域 採用技術・製品 用途 バージョン方針 関連要件・制約 ADR
フロントエンド React 申請・承認画面 サポート中の安定版を固定 FR-001からFR-003 ADR-003
バックエンド Java 業務処理と外部連携 LTS版を使用 CON-002、NFR-007 ADR-004
データベース PostgreSQL 申請・承認・監査データ マネージドサービスの対応版 DR-001、NFR-001 ADR-005
認証 社内IdP 利用者認証 社内標準に従う IF-001、CON-002 ADR-006

3. 共通の採用方針

組織の標準技術と長期サポート版を優先する。バージョンは環境間で統一し、更新時は互換性試験とロールバック手順を用意する。

4. ライセンス・サポート

利用するOSSのライセンスをリリース前に確認する。商用サービスは契約期間、サポート窓口、終了時のデータ取得方法を確認する。

5. 設計上の判断と未確定事項

  • 設計判断: DEC-002に基づきWebアプリケーションとして提供する。
  • ISSUE-040: Javaの採用LTSバージョンを性能検証後に確定する。
  • ISSUE-041: 商用監視サービスの契約プランを費用確認後に確定する。
