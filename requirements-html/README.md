# HTMLスキルの動作確認用サンプル

[index.html](index.html) をブラウザで開いてください。ローカルサーバーやビルドは不要です。

架空の「社内申請管理」を題材に、`skills/create-requirements-html/SKILL.md` の手順と要件定義テンプレートを使って作成しました。実案件の要件や採用判断ではありません。既存のMarkdown資料とスキルは変更していません。

## 手元で試す操作

1. 目次の「機能要件」を開く。
2. 検索に `FR-001` を入力し、1件になることを確認する。
3. `該当なしの文字列` を入力し、0件になることを確認する。
4. 「絞り込みを解除」を押し、カテゴリを「承認」に変更する。
5. 「受入条件」から `FR-001` リンクを押し、絞り込みが解除されて対象へ移動することを確認する。
6. 再び検索で0件にし、ブラウザの印刷プレビューで両方の要件が表示されることを確認する。
7. ウィンドウ幅を狭くし、表だけ横スクロールできることを確認する。

## 検証の限界

- Firefox・Safari・実機モバイル・スクリーンリーダー・物理プリンターは未確認です。
- PDF生成と印刷時の表示制御は確認しましたが、全ページの改ページや印字欠けの目視確認までは行っていません。
- スキルの手順を読み、成果物を生成するところから確認しました。新規セッションでのスキル自動検出・インストール状態の確認は対象外です。
- 競合の実調査、Mermaid変換、設計・開発計画の実案件データによる生成は今回の確認範囲外です。
- サンプル内のAC-IDは架空システムの受入条件です。今回のHTML検証に合格しても、その受入試験に合格したことにはなりません。
