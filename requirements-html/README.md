# HTML文書サイトの動作確認

[index.html](index.html) をブラウザで開いてください。トップページ＋34文書を共通メニューから閲覧できる静的サイトです。サーバー・ビルド・ネットワーク接続は不要です。

## 収録内容

- **要件定義・付録**: 16ページ。ターゲット、関係者、業務フロー、カテゴリ別機能要件、競合調査など。
- **基本・詳細設計・ADR**: 17ページ。API、認証認可、セキュリティ、移行、共通UI、モジュール、データストアなど。
- **開発計画**: 1ページ。
- **記入例**: 元の34文書と同じページに統合。これはテンプレート閲覧サイトであり、実案件の完成済み資料ではありません。
- **図**: Mermaidから生成した9個のSVGと元ソースを収録。
- **以前のサンプル**: 単ページ版は [sample.html](sample.html) に残しています。サイト内の文書数34には含めません。

スキルの配布用テンプレートは `skills/create-requirements-html/assets/site/` にあります。このフォルダはその閲覧用コピーです。既存のMarkdown文書は変更していません。自動同期は行いません。

## 試す操作

1. トップページから「機能要件」を開く。
2. 共通メニューの検索に「API」と入力し、API設計へ移動する。
3. 検索を解除し、詳細設計の「モジュール詳細設計」へ移動する。
4. ページ下の「前」「次」、パンくず、ブラウザの戻る・進むを試す。
5. 「競合調査と機能候補」の記入例にあるFR-002リンクから、機能要件の対応する記入例へ移動する。
6. ターゲット・ステークホルダー・業務フローの図を確認する。図の下ではMermaidソースも開ける。
7. スマートフォン幅では「サイトメニュー」を閉じると本文を広く読める。表・大きな図はその領域内で横スクロールする。

検索は文書名が対象です。全文検索や旧サンプルの機能カード検索とは異なります。

## 検証

配布用テンプレートとこの閲覧用サイトの両方で、以下の構造検査・ブラウザテストは合格しました。実行ブラウザはChromium 151.0.7922.34です。JavaScriptエラー、読み込み失敗、外部HTTP(S)リクエストはいずれも0件でした。

元Markdownの34ファイルとの対応、全ページの構造・リンク・CSS・JS・SVG参照を検査します。ブラウザテストは元の見出し数・表数・行数・本文・コード・Mermaidソースの保持、全34文書の「次」リンク、履歴移動、共通目次、検索と解除、要件参照、390px／1280pxでのはみ出し、SVG表示、JS無効時のページ遷移、印刷用CSSとPDF生成を対象とします。

```sh
python3 -B skills/create-requirements-html/scripts/check_html.py --template requirements-html
python3 -B skills/create-requirements-html/scripts/test_check_html.py
```

ブラウザ検証には保守環境の `playwright-core`、`markdown-it` とChromiumを使用します。実行手順はスキルの `references/site-guide.md` を参照してください。閲覧時の依存ではありません。

Firefox・Safari・実機モバイル・スクリーンリーダー・物理プリンターは未確認です。印刷はブラウザでのPDF出力までで、全ページの改ページを目視保証するものではありません。
