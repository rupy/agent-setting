機能要件

1. 機能要件の記述規則

要件IDはFRから始め、一つのIDに一つの検証可能な振る舞いを記載する。 Must要件には上位要求と受入条件を対応させる。 機能一覧と個別機能要件は「経費申請」「承認」「会計連携」のカテゴリでまとめる。 要件IDはカテゴリをまたいで一意とし、分類を変更しても採番し直さない。

3. 個別機能要件

3.1 経費申請

FR-001 経費申請の提出

  • 概要: 下書きの経費申請を承認者へ提出できること。
  • 根拠: 紙による申請をオンラインへ移行するため。
  • 対象利用者: 申請者
  • 利用者が実現したいこと: 支払い後に経費情報と領収書を提出する。
  • 関連するスコープ: 経費申請、領収書
  • 関連する業務フロー: BP-001
  • 事前条件: 申請者がログインし、申請が下書き状態である。
  • トリガー: 申請者が提出を実行する。
  • 入力: 支払日、金額、経費区分、支払先、利用目的、領収書画像
  • 基本処理:
    1. 必須項目と入力形式を検証する。
    2. 組織情報から承認者を決定する。
    3. 状態を上長承認待ちへ変更する。
    4. 承認者へ通知する。
  • 出力: 提出結果、申請番号、現在の状態
  • 事後条件: 承認者が承認待ち一覧から申請を確認できる。
  • 例外: 入力不足または承認者未設定の場合は提出せず、理由を表示する。
  • 権限制御: 申請の所有者だけが提出できる。
  • 優先度: Must
  • 上位要求: BO-001、BO-002、BP-001
  • 受入条件: AC-001、AC-002

FR-002 申請状況の参照

  • 概要: 申請者が自分の申請の現在の状態を参照できること。
  • 根拠: 申請の進捗を把握するため。
  • 対象利用者: 申請者
  • 利用者が実現したいこと: 提出した申請がどの段階にあるか確認する。
  • 関連するスコープ: 経費申請
  • 関連する業務フロー: BP-001
  • 基本処理: 閲覧権限を確認し、対象申請の現在の状態を表示する。
  • 権限制御: 他の申請者の申請は閲覧できない。
  • 優先度: Must
  • 上位要求: BO-002、BP-001
  • 受入条件: AC-003

3.2 承認

FR-003 申請の承認・差し戻し

  • 概要: 承認者が割り当てられた申請の承認結果を記録できること。
  • 根拠: 申請に対する判断をシステム上で共有するため。
  • 対象利用者: 承認者
  • 利用者が実現したいこと: 内容を確認して承認または差し戻しを行う。
  • 関連するスコープ: 承認
  • 関連する業務フロー: BP-001
  • 事前条件: 対象申請が上長承認待ちである。
  • 基本処理: 承認または差し戻しの結果を記録し、対応する状態へ変更する。
  • 権限制御: 対象申請に割り当てられた承認者だけが操作できる。
  • 優先度: Must
  • 上位要求: BP-001
  • 受入条件: AC-004

3.3 会計連携

FR-004 会計連携用CSVの出力

  • 概要: 経理確認済みの経費を会計システムへ取り込むためのCSVを出力できること。
  • 根拠: 会計システムへの転記作業を減らすため。
  • 対象利用者: 経理担当者
  • 利用者が実現したいこと: 確認済みの経費データを会計システムへ受け渡す。
  • 関連するスコープ: 会計連携
  • 関連する業務フロー: BP-001
  • 基本処理: 経理確認済みデータを会計取込用CSVとして出力する。
  • 例外: 出力失敗時は登録完了とせず、BR-003に従う。
  • 権限制御: 経理担当者だけが出力できる。
  • 優先度: Should
  • 上位要求: BO-001
  • 受入条件: AC-005

4. 認証・認可

  • 社内認証基盤で認証された利用者だけが利用できる。
  • 申請者は自分の申請、承認者は割り当てられた申請を閲覧できる。
  • 経理担当者は上長承認済みの申請を閲覧・処理できる。
  • システム管理者権限だけでは申請内容を閲覧できない。

5. 監査・履歴

申請提出、承認、差し戻し、経理承認、CSV出力、権限変更について、 実行者、対象、日時、変更前後の状態、結果を記録する。利用者は履歴を変更できない。

6. エラー処理

  • 入力エラーは対象項目と修正方法を表示する。
  • 一時的な外部連携エラーでは入力済み内容を失わせない。
  • 内部情報やスタックトレースを利用者へ表示しない。
  • 業務継続に影響するエラーは監視対象として運用担当者へ通知する。
